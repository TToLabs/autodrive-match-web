# AutoDrive MATCH — demo web (mirror)

Versión **de demostración** de la app móvil de AutoDrive MATCH, publicada con GitHub Pages:
https://ttolabs.github.io/autodrive-match-web/

- Solo la app de usuarios (conductor y dueño). Funciona con datos de ejemplo: **sin pagos reales,
  sin cuentas reales y sin Supabase**.
- El panel de administración requiere servidor y no se publica aquí.
- Generado automáticamente desde el repositorio privado `TToLabs/autodrive-match`
  (`node scripts/construir-estatico.mjs` con `BASE_PATH=/autodrive-match-web`). No editar a mano.
